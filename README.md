# IRON MAN 2058 · Web App V1.0

## Schnellster Start mit GitHub Pages
1. Auf GitHub ein neues Repository anlegen, z. B. `iron-man-2058`.
2. Die Dateien aus diesem Ordner in das Repository hochladen.
3. Repository → Settings → Pages.
4. Unter “Build and deployment” `Deploy from a branch` wählen.
5. Branch `main`, Ordner `/ (root)` auswählen und speichern.
6. Nach kurzer Zeit erscheint dort der öffentliche HTTPS-Link.
7. Den Link auf dem iPad in Safari öffnen → Teilen → „Zum Home-Bildschirm“.

## Dateien
- `index.html` – Cockpit
- `style.css` – Design
- `app.js` – Navigation und Touch-Interaktion
- `manifest.webmanifest` – Web-App/Startbildschirm

Die Company-Navigation funktioniert hier als echte Safari-Webseite und ist nicht mehr von der iPad-Dateivorschau abhängig.
